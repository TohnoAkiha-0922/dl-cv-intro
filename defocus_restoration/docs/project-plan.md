# 项目边界与后续研究

项目名称：基于光学成像模型的离焦图像复原。
确立日期：2026-10-19。依据：本次用户明确选题并要求 AI 内阁生成项目。

## 第一版问题

在已知圆形光瞳及离焦参数、固定采样的单色非相干模型下，比较传统 Wiener 和轻量条件网络，并检查改变离焦后能否继续复原。首先理解模型与评价，再研究改进。

第一版包含：程序生成的线性强度场景、离焦 PSF、周期卷积与简化高斯噪声、验证集选参、独立测试、轻量网络入口、MATLAB 对照及数值核查。学习成果和软件完整性不等于算法创新或真实相机性能。

## 保留自己的计算成像主线

主要积累是光学建模、逆问题、图像复原与实验方法。王老师公开简介提到计算机视觉、图像处理、语义/实例分割和卫星影像解译，并列有数字全息、影像质量评价等项目；这些能作为交叉沟通线索，不能据此认定老师当前承接本题或有对应实验条件。

向老师汇报时展示 PSF、复原和跨离焦曲线，并询问组内是否有适合验证的真实数据或相关复原任务。遥感分割评价可以后加，当前核心不依赖遥感数据。

## 有结果之后再选择一个延伸

- 用实测标定 PSF 替代理想光瞳模型，并处理零填充、边缘和像素积分。
- 在不同场景分布上测试，明确合成到自然图像的差距。
- 比较给网络离焦参数与不给参数的受控实验，检验条件信息的作用。
- 取得合适数据与指导后探索多幅观测、相位恢复或其他更具体的计算成像测量。

先做一个延伸；真实位移、像差、多波长、盲估计、遥感分割不能在第一版同时展开。
