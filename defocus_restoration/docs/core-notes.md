# 核心物理与数值约定

## 这个项目模拟什么

本项目采用**单色、非相干、近轴、空间不变**成像模型。输入是物体在理想像面上的二维线性强度分布；输出是理想点采样探测器记录的强度。图像中的每个点共享同一个点扩散函数（PSF）。不包含景深随位置变化、真实镜头像差、畸变、有限像素面积积分、曝光饱和及真实相机标定。

它是学习“正向成像与反向重建”的合成实验，不应以这些合成数据上的高分推断真实相机效果。

## 从光瞳到 PSF

采样间距 `dx = pixel_pitch_um`，波长 `lambda = wavelength_nm / 1000`，均以微米计。`f_number` 为像方近轴 F 数。空间频率格由 `fftshift(fftfreq(N, d=dx))` 生成，单位为每微米。

相干振幅截止频率为：

```text
fc = 1 / (2 * lambda * F#)
rho² = (fx² + fy²) / fc²
P(fx, fy) = 1[rho² <= 1] * exp(i * 2π * w * rho²)
```

这里 `w = defocus_waves` 表示二次离焦波前在瞳边缘相对瞳中心的光程差除以波长。`w=0.5` 表示边缘相对中心的光程差为半个波长。它不是高斯模糊的 sigma，也不是传感器移动的毫米数。本项目没有标定它与具体镜头机械位移的换算关系。

先对中心排列的光瞳作逆傅里叶变换，再取振幅模方并归一化：

```text
A = fftshift(ifft2(ifftshift(P)))
h = abs(A)² / sum(abs(A)²)
```

`h` 是中心排列的强度 PSF，非负且所有像素之和为 1；这使均匀强度和总能量在周期成像中守恒。对于这里的对称圆形光瞳、只有离焦且物体非相干的模型，正负离焦的强度 PSF 相同。因此，不能仅凭这类模糊图判断离焦符号。增加其他像差或额外测量后才可能打破这个对称性。

即使 `w=0`，系统仍存在有限孔径衍射，清晰场景经过它后也不是逐像素原样返回。

## 为什么默认像素间距是 2 微米

非相干强度 OTF 截止频率为 `1 / (lambda * F#)`，是相干截止频率的两倍。因此 Nyquist 条件为：

```text
1 / (2 * dx) >= 1 / (lambda * F#)
dx <= lambda * F# / 2
```

默认 `lambda=0.55 um`、`F#=8` 时，最大允许像素间距是 `2.2 um`；默认 `dx=2.0 um` 满足条件。`OpticsConfig` 会拒绝违反该条件的设置，避免用错误采样得到看起来合理的 PSF。

这是避免强度带宽混叠的必要条件，并不保证任意参数下数值精度足够。固定 `dx` 增大 `N` 会扩大视场、加密频率光瞳采样；极小 `dx` 配合很小 `N` 会使光瞳只有少数采样点。较大离焦时 PSF 可能延伸到边缘并周期回卷，应增大视场并检查 PSF 边缘能量，必要时做采样收敛实验。

## 模糊、噪声与周期边界

成像模型为 `y = h ⊛ x + n`，其中 `⊛` 是**周期卷积**，`n` 是零均值独立高斯强度噪声。默认噪声标准差 `0.005` 对应强度满量程的 0.5%。这不是泊松光子噪声模型。

中心排列的 PSF 先转成 FFT 顺序：

```text
H = fft2(ifftshift(h))
y = real(ifft2(fft2(x) * H))
```

周期边界意味着右边界的光可以卷回左边界，上边界也与下边界相接。成像、维纳复原与神经网络卷积均应按这一约定理解。真实照片通常不满足周期假设，因此边缘区域可能出现不真实的回卷或振铃。第一版没有用零填充伪装成真实边界；后续研究可以明确改用扩展视场、反射延拓或裁剪有效区域，并同步修改正反算子。

观测和复原数组始终保存**未裁剪浮点值**。高斯噪声会产生负值，逆滤波也可能产生小于 0 或大于 1 的值，这些数值有助于理解噪声与振铃。若为了显示或以满量程 1 计算指标而使用 `clip(0,1)`，必须对所有被比较方法使用同样规则，并明确标注。核心指标函数本身不裁剪。

## 维纳复原与不能恢复的信息

给定正确 PSF，用常数正则项 `K = balance > 0`：

```text
x_hat = real(ifft2(conj(H) * fft2(y) / (abs(H)² + K)))
```

这里采用常数噪声与信号功率比的简化近似，也可视为零阶 Tikhonov 频域正则化。`K` 太小会放大噪声；太大会牺牲细节。OTF 为零的频率没有观测信息，单幅图像的线性逆滤波无法恢复它们。网络可能依据训练分布补出结构，但补出的结构不等于真实被测细节。

参数选择应在验证集完成，再固定后评估测试集。不要反复观察测试分数来选最优参数，也不要把已知 PSF 的方法与未知退化的方法不加说明地直接比较。

## 场景、划分与指标

`make_scene` 是几何形状、细线和正弦纹理的可复现组合，输出 `[0,1]` 的 `float32` 线性强度，不下载任何外部数据。它只覆盖一个受控分布，应在后续加入独立外部场景检验泛化。

`scene_seed(split,index,base_seed)` 为每个分区预留一百万个源种子：

```text
seed = (3 * base_seed + split_id) * 1_000_000 + index
split_id = train:0, val:1, test:2
0 <= index < 1_000_000
```

同一个 `base_seed` 下，各分区源种子严格不相交。不同离焦或噪声版本必须留在原图所属分区；自备照片及其裁剪、连拍、重复来源也应按来源分组。种子隔离不代表合成分布足够真实，也不代替独立实验。

`load_grayscale` 将普通图片当作 sRGB，先解码到线性 RGB，按线性亮度权重变灰度，再居中裁剪和缩放。此过程不做 ICC 色彩管理，也不等同 RAW 线性标定。请不要把 gamma 编码的 JPEG 值直接解释成物理线性光强。

PSNR 使用 `10*log10(data_range²/MSE)`，默认 `data_range=1`。SSIM 使用 `11x11`、`sigma=1.5` 的高斯局部窗口和总体协方差，排除 5 像素边缘；不同实现的窗口、边界和协方差约定可能产生分数差异。这两个指标只能评价与已知参考图像的相似度，还需要看局部细节、失败情况和物理一致性。

## 已执行的核心检查

`tests/test_physics.py` 包含正负离焦强度对称性、PSF 能量与 OTF 直流、相干光瞳与非相干截止频率、奇偶数组的脉冲定位、均匀强度与总能量守恒、无噪与有噪已知 PSF 复原改善、未裁剪观测、数据源划分、sRGB 线性化和异常输入检查。运行方式：

```powershell
python -m pytest tests/test_physics.py -q
```

这些检查核验离散教学模型内部的一致性；它们不构成真实镜头标定或实际拍摄效果的验证。
