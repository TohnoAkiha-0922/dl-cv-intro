## 网络训练与保存后重载

执行 `./run_train.ps1`，实际解释器为上述 `cv_pytorch` 环境。

- 网络参数 **29,689**，输入为原始含噪强度和真实离焦参数平面。
- 96 张训练底图、16 张验证底图，各对应 0、0.4、0.8 waves，共 288/48 样本。
- 128×128，batch size 8，Adam 学习率 0.001，12 轮 CUDA 训练。
- 第 1 轮验证原始输出 MSE **0.0043503**；最低值出现在第 12 轮，为 **0.0027627815**。
- 新进程从 `outputs/network/best.pt` 重载模型和成像配置，在 12 张独立测试底图 × 6 种离焦上完成 72 个观测的三方法比较。

完整指标见 `outputs/network-evaluation/aggregate.csv` 和 `per-sample.csv`。以下为部分均值，按“含噪观测 / 已知 PSF 维纳 / 条件网络”顺序：

- 0.2 waves，训练未见的参数插值：PSNR **25.584 / 29.816 / 27.530 dB**；SSIM **0.8830 / 0.8791 / 0.9066**。
- 0.8 waves，训练见过该参数、测试底图未见：PSNR **20.551 / 23.244 / 23.000 dB**；SSIM **0.6565 / 0.7210 / 0.7407**。
- 1.2 waves，训练范围之外：PSNR **18.944 / 21.853 / 19.068 dB**；SSIM **0.5796 / 0.6820 / 0.5604**。

当前六个测试离焦量下，网络平均 PSNR 均低于维纳；在五个范围内参数上网络 SSIM 较高，1.2 waves 外推时 SSIM 低于观测。指标选择会影响判断，不能声称网络全面胜出。该运行检验了学习与评估流程，未做自然图像或真实相机实验。

读取三份 manifest 后，训练/验证/测试的不同底图种子数量为 96/16/12，三组两两交集均为空。测试的 72 个观测对应 216 条方法指标，传统批量测试有 112 条方法指标，与文件记录数一致。

另用 PyTorch 环境执行 `python -m unittest discover -s tests -p test_learning.py -v`，**4 项通过**，覆盖条件通道、奇数尺寸输出、真实优化与 checkpoint 重载、底图分区。该环境没有 pytest，因此使用 Python 内置 unittest 执行这些检查。

## MATLAB 与 Python 数值一致性

MATLAB 执行 `run('D:/code.c/Project20/defocus_restoration/matlab/lesson1_defocus.m')` 成功，生成 `.mat` 和六图。MATLAB 场景的观测 PSNR **22.683 dB**，维纳复原 **27.186 dB**。

## 结论边界

已验证的是理想离散模型内部一致性、代码入口和一轮固定配置的学习实验。尚未验证：真实光学系统标定、机械离焦量换算、有限像素积分、彩色/多波长成像、空间变化模糊、真实噪声、自然图像与真实拍摄泛化。项目第一版可供学习与向导师展示方法；后续研究贡献需要新的问题和独立证据。
