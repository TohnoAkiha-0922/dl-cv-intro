# 从课程走到项目

这是已确认项目的学习入口，建议每次只完成一个能解释的实验。网络不是第一课。

## 第一次：读懂六幅图

运行 `python demo.py`，打开 `outputs/demo/comparison.png`。先区分物体强度、光瞳相位、强度 PSF、观测强度与复原图；只有物体强度图进入这里的非相干卷积成像。

能回答：PSF 表示什么？为什么相位只在光瞳中定义？为什么相机记录强度？为什么 w=0 时还有模糊？PSF 归一化为 1 有什么意义？

## 第二次：只改变离焦

分别执行 `python demo.py --defocus 0 --output outputs/focus` 和 `python demo.py --defocus 1.2 --output outputs/defocus12`。其余参数固定。观察 PSF、条纹和边界。`defocus` 的单位是波长，不是高斯标准差或镜头移动距离。

课程连接：圆孔衍射、傅里叶变换、非相干成像、点扩散函数、OTF/MTF。阅读 `docs/core-notes.md` 并对照 `defocuslab/optics.py`。

## 第三次：噪声与复原

比较 `--noise-std 0` 和 `--noise-std 0.005`。然后固定噪声，仅改 `--balance 0.001` / `--balance 0.01`。小正则参数可能把噪声放大，视觉更锐也不一定更接近真值。

课程连接：卷积定理、逆滤波、频率零点、正则化。阅读 `defocuslab/restoration.py`。试着自己写出 Wiener 分母，并解释每一项。

## 第四次：完整实验

运行 `python experiment.py`。验证集负责选参数，测试集负责汇报结果。查看 `validation.csv`、`manifest.json`、`test_metrics.csv` 和 `defocus_curve.png`。同一清晰原图的不同模糊版本不能分到不同数据分区。

尝试解释：不同离焦程度为何不一定使 PSNR 单调下降？全图 PSNR 与局部条纹是否给出一致印象？周期边界会产生什么影响？

## 第五次：学习网络

按 README 使用已有 `cv_pytorch` 环境运行小型训练与评估。先读数据样本和损失计算，再读 U-Net；先确认它真的能学、能保存和重载，再增加训练规模。网络知道离焦参数，这里不做盲复原。

检查清晰物体、离焦观测、传统复原、网络输出。网络没有胜过传统算法也有价值：分析训练时长、数据分布、参数输入与未见离焦条件，而不是只选好看的图。

## MATLAB 对照

在 MATLAB 中运行 `matlab/lesson1_defocus.m`。它不依赖图像处理工具箱。先只看第 3、4 节；Python 和 MATLAB 使用同样的光瞳、PSF、OTF 与 Wiener 约定，但随机场景和噪声样本不同，不直接比较两张图的分数。

## 每次实验写五句话

1. 本次想检验什么问题？
2. 只改变了哪个参数？
3. 实际看到了什么数值和现象？
4. 现象与哪条公式或假设相关？
5. 下次需要排除什么其他解释？

每周投入约四小时可以作为起步安排；按理解与课程负担调整，不把上面的步骤当固定完成期限。
